🔗 [GitHub / Code](https://github.com/pswirgie/Animshell)


Animshell is a simplified reimplementation of the Bash shell, written in C as part of the 42 curriculum.
The goal: rebuild the behavior of a Unix shell (reading commands, executing processes,
handling pipes and builtins) without relying on any existing shell library.

👥 **Built as a pair with [stepouik](https://github.com/stepouik)**.

#### My contributions:
- Redirections / heredoc
- Builtins: cd, echo, exit
- Pipelines
- Command execution

#### Features ✅
- [X] Command-line parsing
- [X] Simple command execution
- [X] **Pipeline** handling (`|`)
- [X] Partial implementation of **builtins**
- [X] Signals
